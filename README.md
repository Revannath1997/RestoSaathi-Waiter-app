# RestoSaathi Waiter App

A comprehensive restaurant management system where waiters can digitize menu cards using OCR, manage orders, and integrate with kitchen and manager dashboards.

## Features

### For Waiters
- **Signup with Manager Code**: One-time signup codes generated by restaurant managers
- **Menu Card Upload**: Capture menu card photos directly from phone
- **Automatic OCR Processing**: AI-powered menu card digitization
- **Smart Order Taking**: Select items from digitized menu or voice orders
- **Voice Order Support**: Speak orders for hands-free ordering
- **Real-time Order Status**: Track order progress from creation to completion
- **Order History**: View past orders and details
- **Offline Support**: Minimal offline functionality with AsyncStorage

### For Restaurants
- **Menu Management**: Automatic extraction and organization by category
- **Order Tracking**: Real-time kitchen and manager notifications
- **Kitchen Display**: Integration-ready for KDS (Kitchen Display System)
- **Analytics**: Order metrics and waiter performance

## Tech Stack

### Backend
- **Framework**: Node.js with Express.js
- **Database**: PostgreSQL with Prisma ORM
- **Authentication**: JWT (JSON Web Tokens) with bcryptjs
- **File Upload**: Multer
- **APIs**: RESTful API design

### Frontend
- **Framework**: React Native with Expo
- **Navigation**: React Navigation (Stack & Drawer)
- **HTTP Client**: Axios
- **Camera**: expo-camera & expo-image-picker
- **Voice**: expo-voice (simulated)
- **Storage**: AsyncStorage & SQLite (offline)
- **UI Components**: React Native core components with custom styling

### Infrastructure
- **Database**: PostgreSQL 15
- **Containerization**: Docker & Docker Compose
- **Environment Management**: dotenv

## Getting Started

### Prerequisites
- Node.js 16+ and npm/yarn
- PostgreSQL 15
- Expo CLI (`npm install -g expo-cli`)
- Git

### Quick Setup (20 minutes)

See [SETUP.md](./SETUP.md) for quick start instructions.

### Manual Setup

#### 1. Database Setup
```bash
# Start PostgreSQL (using Docker)
docker-compose up -d

# Or install PostgreSQL locally and create database
createdb resto_waiter
```

#### 2. Backend Setup
```bash
cd backend

# Copy environment file
cp .env.example .env

# Install dependencies
npm install

# Setup Prisma
npm run prisma:generate
npm run prisma:migrate

# Start development server
npm run dev
```

The backend will run on `http://localhost:3000`

#### 3. Frontend Setup
```bash
cd frontend

# Copy environment file
cp .env.example .env

# Install dependencies
npm install

# Start development server
npm start
```

Choose platform:
- **Web**: `w`
- **iOS**: `i` (requires macOS)
- **Android**: `a`

## API Endpoints

### Authentication
- `POST /api/v1/auth/generate-waiter-code` - Generate manager signup code
- `POST /api/v1/auth/signup` - Waiter signup with code
- `POST /api/v1/auth/login` - Waiter login
- `POST /api/v1/auth/verify` - Verify JWT token

### Orders
- `POST /api/v1/orders/create` - Create new order
- `GET /api/v1/orders/:orderId` - Get order details
- `GET /api/v1/orders/pending` - Get pending orders
- `PUT /api/v1/orders/:orderId/status` - Update order status
- `POST /api/v1/orders/:orderId/send-to-kitchen` - Send to kitchen

### Menu & OCR
- `POST /api/v1/menu/upload` - Upload menu card image
- `POST /api/v1/menu/process/:uploadId` - Process menu with OCR
- `GET /api/v1/menu/restaurant/:restaurantId` - Get menu items
- `GET /api/v1/menu/processing/:processingId` - Get processing status

### Notifications
- `GET /api/v1/notifications/order/:orderId` - Get order notifications
- `GET /api/v1/notifications/unread` - Get unread notifications
- `POST /api/v1/notifications/:notificationId/read` - Mark as read
- `GET /api/v1/notifications/stream/:orderId` - Order status stream

## Database Schema

### Core Models
- **Restaurant**: Restaurant information
- **Branch**: Restaurant branches
- **Waiter**: Waiter profiles
- **WaiterSignupCode**: One-time signup codes
- **WaiterSession**: Active sessions and tokens
- **Order**: Order details and status
- **OrderItem**: Individual items in order
- **OrderNotification**: Order updates and notifications
- **MenuItem**: Menu items with pricing
- **MenuCardUpload**: Uploaded menu card images
- **MenuProcessing**: OCR processing records

## Troubleshooting

### PostgreSQL Connection Error
```bash
# Check if PostgreSQL is running
docker-compose ps

# Restart PostgreSQL
docker-compose restart postgres
```

### Port Already in Use
```bash
# Change PORT in .env or kill process
kill -9 $(lsof -t -i:3000)  # macOS/Linux
```

### Module Not Found Errors
```bash
# Reinstall dependencies
rm -rf node_modules package-lock.json
npm install
```

### Expo Connection Issues
```bash
# Clear Expo cache
expo start --clear

# Try tunnel mode
expo start --tunnel
```
